# Neural Networks: Course Portfolio

Portfolio for Artificial Neural Networks and Deep Learning (Insper, 2026.2).

The website is built with [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) and deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.

**Live site:** https://malusevilha.github.io/neural-networks/

## Local development

### Setup

Create and activate a virtual environment, then install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Serve locally

```bash
mkdocs serve
```

Open the local address printed in the terminal (usually `http://127.0.0.1:8000`) to preview the site with live reload.

### Reproduce an exercise

Each exercise report is generated by a single, reproducible script that saves its own figures. Run it from the repository root, for example:

```bash
python3 docs/exercises/data/code/data_activity.py
python3 docs/exercises/perceptron/code/perceptron_activity.py
python3 docs/exercises/mlp/code/mlp_activity.py
```

The Data exercise additionally needs the Kaggle **Spaceship Titanic** `train.csv` placed at `docs/exercises/data/data/train.csv` (not committed to the repository, see that folder for details).

## Structure

```
docs/
  index.md                    # home page
  about.md
  exercises/
    index.md                  # exercises overview
    data/                     # Exercise 1
      index.md
      code/data_activity.py
      data/train.csv          # not committed: see Data exercise page
      figures/
    perceptron/               # Exercise 2
      index.md
      code/perceptron_activity.py
      figures/
    mlp/                      # Exercise 3
      index.md
      code/mlp_activity.py
      figures/
  projects/
    index.md
  stylesheets/extra.css      # custom red theme on top of Material
  javascripts/mathjax.js     # LaTeX rendering
.github/workflows/main.yaml  # build + gh-deploy on push to main
mkdocs.yml                   # site configuration and navigation
requirements.txt
```

## Deployment

The GitHub Actions workflow in `.github/workflows/main.yaml` installs the dependencies and runs `mkdocs gh-deploy` on every push to `main`, which builds the site and force-pushes it to the `gh-pages` branch.
